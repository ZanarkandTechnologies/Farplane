# Review Leads Golden Trace

## Input

A consultancy won two clients from 18 warm messages and wants to add content,
cold email, and paid ads simultaneously. It has no stable reply or close rate.

## Decisive trace

1. Warm outreach has a positive but too-small sample; other channels are unused and not currently required.
2. Core Four breadth is not the issue. `More → Better → New` is partial because the working method lacks repetitions and baseline rates.
3. The binding constraint is insufficient evidence about the present channel, not absence of three additional channels.
4. Before → After: 18 uninstrumented messages → one bounded warm-outreach cohort with asks, replies, qualified conversations, and closes recorded.
5. A daily outreach target may structure the test, but “100” is not a universal quota.
6. Run a fixed message/segment through the next 30 qualified contacts; then improve the largest observed drop or stop if fit is weak.

## Accepted output

Recommend `More` in the already-promising channel, label content/cold/ads as
candidate-later or not-currently-required, and resist a four-channel plan.
Generic advice would prescribe omnichannel activity without learning which
input or constraint matters.
