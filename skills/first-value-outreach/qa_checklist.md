# First Value Outreach QA Checklist

Read before execution and apply again to the finished packet, contribution,
and message. Ask an independent reviewer to try to reject material packages.

## Checks

1. **Traceable relevance** — one researched person and dated professional
   signal support the contribution; private pain, sensitive traits, and
   biography theater are absent or explicitly unknown.
2. **Standalone value** — the artifact gives the recipient a useful insight,
   decision aid, explanation, or proof even if they never reply, buy, share
   data, or book a call.
3. **Bounded asymmetry** — creator effort, recipient time, claims, and scope
   match the declared budget; a smaller artifact was preferred over an
   unnecessary demo, and no hidden discovery homework remains. When a demo is
   justified, the packet separately records the accepted solution boundary,
   optional realism preparation, actual implementation owner, and inspection
   surface; `demo-realism` is never mislabeled as the builder.
4. **Correction-first learning** — the message leads with the artifact, names
   its limit, asks one low-effort correction or redirect question, defines the
   learning objective and falsifier, and has a graceful stop condition.
5. **Permission integrity** — contact, follow-up, CRM writes, enrichment,
   spend, use of private data, endorsement, and public amplification remain
   unapplied without exact human approval; readiness is `send | revise | stop`.

## Reviewer Output

Return each failed check as `violation | deferral`, cite exact evidence, name
the smallest repair, and finish with `pass | revise | block`.
