## Body

This week’s changes moved the AI office from a map of agents toward an operated
system. Here are the four highest-impact releases, grouped by what they unlock.

## Work ownership

> ### Durable tasks now keep one identity
>
> **Changed:** Every Farplane ticket can own exactly one durable Codex task.
>
> **Impact:** Work can be paused and reopened without splitting ownership or
> forcing the operator to reconcile a ticket with a separate conversation.
>
> **Evidence:** The release was backed by 73 Core tests and 28 UI tests.

## Capability and routing

> ### The capability map now describes outputs
>
> **Changed:** Farplane now maps seven departments to nineteen workflow roots
> and ten artifact specialists. Integrations are no longer presented as
> top-level capabilities.
>
> **Impact:** The map shows what the office can produce, not merely which tools
> are connected.
>
> **Evidence:** The verified map contains zero integration nodes at the
> capability layer.

> ### Specialist dispatch now carries project context
>
> **Changed:** Selecting a project and an outcome creates canonical specialist
> work with the project’s task context attached before the worker appears.
>
> **Impact:** Specialist stations now open inspectable, owned work instead of
> acting as decorative UI.
>
> **Evidence:** The weekly proof confirms project-bound specialist dispatch;
> outcome metrics remain unavailable.

## Content intelligence

> ### External-source reading now has clearer surfaces
>
> **Changed:** Content and news remain chronological, while deeper video
> dossiers focus on evidence and reporting.
>
> **Impact:** Each feed has one job, reducing overlap and making research output
> easier to scan.
>
> **Evidence:** The consolidated Content Intelligence flow is verified; no
> public usage metric was available for this interval.

That’s the release set for the week.

Kenji
