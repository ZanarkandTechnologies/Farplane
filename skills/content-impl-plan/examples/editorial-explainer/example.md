# Evidence-Led Editorial Explainer

Input: explain why competent AI agents drift across handoffs to a technical
founder who believes longer prompts should solve the problem.

## Compact accepted shape

```text
ICP:
  starting_belief: better prompts prevent drift
  objection: shared state is process overhead
  must_believe_after: one tiny persistent state surface beats repeated summaries
  action: make every agent read ticket, program, and progress

Story:
  promise: see the exact moment the team forks
  mechanism: the verb "prove" disappears in a summary
  proof: two competent outputs both pass against different goals
  turn: the failure lives between workers
  payoff: shared state exposes disagreement before execution

Beat:
  narration: "One handoff later, the word prove is gone."
  visual: preserve the task page as paper; circle "prove"; pass the copy across
    three workers; visibly remove only that semantic unit
  function: explanation
  viewer_state: summaries feel safe -> sees lossy semantic compression
  asset: labeled reconstruction, material=paper, motion=reveal_cause

Asset decision:
  select sanitized ticket excerpt as direct annotated evidence
  select labeled semantic-deletion reconstruction as explanation
  reject generic signal-decay chart: decoration with no stronger proof job

Scene asset bundle:
  shared_background:
    asset: continuous warm paper-and-worktable plate
    packet: generated texture packet; commercial-use receipt; 1920x1080
  main_topic_asset:
    asset: transparent grayscale handoff-document cutout
    packet: sanitized source document + extraction recipe + clean-alpha check
  foreground_asset:
    asset: transparent passing-hand and desk-edge cutout
    packet: generated/source packet + rights note + parallax/occlusion check
  layer_order: background -> document -> hand/desk edge
  readiness: asset_packet_ready until all three files and assembled frame pass
  rejection: a document card, rounded panel, or label is not a gathered layer

Persona gate:
  founder: 4+/5 comprehension, relevance, trust, action clarity
  operator: exact state-file responsibilities are executable
  skeptic: longer-prompt objection is answered by the surviving-state mechanism
  verdict: pass only with no evidence blocker and an independent receipt
```

Why it passes: the hook, evidence, mechanism, and action all change the same
ICP belief; assets are selected for jobs rather than visual variety; the
persona gate can block production.
