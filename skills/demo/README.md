# Demo

Default narrated recap workflow for material implementation Goals.

After QA passes, `$demo` turns verified ticket context, diagrams, screenshots,
tests, and review evidence into a 45–90 second lead-engineer MP4 organized as
Before, After, Example, Key decisions, and compact Proof. The stable
recipe lives in `references/lead-engineer-recap.md`; production artifacts live
under `tickets/TASK-XXXX/artifacts/demo/`.

Direct non-Goal changes do not require this phase.
