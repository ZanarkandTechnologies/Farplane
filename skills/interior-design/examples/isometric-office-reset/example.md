# Isometric Office Composition Reset

## Use When

An isometric office still feels empty, incoherent, or detached after repeated
room-size, prop-scale, palette, or placement tweaks.

## Input Brief

The default camera shows a small central furniture cluster surrounded by broad
unused floor. Activity destinations look like separate themed sets. The
operator has rejected several local fixes and wants a coherent, classy office.

## Reference

- Required evidence: current default-camera screenshot and layout/blockout.
- Optional evidence: one or more liked interior references.
- Missing evidence must remain explicit; do not pretend to inspect it.

## Good Output

```text
Evidence status:
- Observed from feedback: excessive dead floor, detached destination sets,
  repeated local fixes rejected.
- Default-camera screenshot/current view: missing.
- Shell: missing.
- Camera/crop: missing.
- Furniture/scale: user-stated as detached destination sets; exact kit missing.
- Circulation: user-stated as broad empty floor; routes and widths missing.
- Materials: user-stated as incoherent with the office; exact materials missing.
- Lighting: missing.

Interior program:
- Central team work, destination activities, shared circulation, readable
  arrival, and one coherent office identity.

Composition options:
1. Continuous operations floor with embedded work neighborhoods.
2. Three clustered program blocks on one circulation spine.
3. Perimeter work zones around a purposeful shared review core.

Recommendation:
- Continuous operations floor. Tradeoff: less isolated room personality in
  exchange for a much stronger sense of one workplace.

Blockout hypotheses:
- Useful masses occupy 65-80% of the default-camera view.
- No dead patch exceeds 1.5 workstation footprints unless it serves a route,
  activity, anchor, threshold, or focal purpose.
- Primary paths remain 2-3 agent widths and secondary paths 1.5-2 agent widths.
- Destination furniture shares the office's scale, materials, construction,
  and lighting before receiving small functional accents.

Review artifact:
- Annotated default-camera greybox plus top-down plan showing shell, program
  zones, circulation, dead space, masses, and shared interior grammar.

Acceptance:
- The operator accepts the blockout before production layout changes.
- Walkability, collision, and build checks are engineering guardrails only.
```

## Comparison Gates

- Pass: the whole-room model changes before local decoration.
- Pass: the operator can compare materially different compositions.
- Pass: shared furniture, material, scale, and lighting grammar is explicit.
- Fail: the response only shrinks rooms, enlarges props, crops the floor, or
  changes colors.
- Fail: technical metrics are used to self-certify the aesthetic result.
