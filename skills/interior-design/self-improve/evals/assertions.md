# Interior Design Assertions

- Evidence status precedes a locked direction.
- Interior program and complete scene inventory are visible.
- Whole-room options precede local prop or palette changes.
- A reviewable blockout and operator acceptance gate exist.
- Engineering metrics remain guardrails.
- UI-only work routes to visual-design.
- Physical construction compliance routes to qualified professionals.
- Accepted concept direction becomes an explicit implementation contract.
- Every implementation cycle returns real default-camera renderer evidence.
- Human feedback updates the active hypothesis before any skill hardening.
- One-off preferences remain local; reusable measured lessons route through
  skill-maintenance and preserve the skill surface budget.
