# Video Production QA Checklist

- [ ] `config.toml` was read before method or style defaults were selected;
  invocation values win and no credential value was loaded from skill config.
- [ ] The visual-direction result matches exactly one of the four cases:
  method default, profile only, inspiration over method default, or composed.
- [ ] A named profile supports the selected method and its `profile.md`,
  `prompts.md`, and collocated `example.md` agree on grammar and constraints.
- [ ] Composition assigns reusable aesthetic/motion grammar to the profile and
  task facts, approved source assets, and motifs to Inspiration evidence;
  conflicts produce a blocker instead of a silent blend.
- [ ] Style ingestion consumes a saved `ingest-content` capture, preserves
  provenance and observation/inference boundaries, rejects collisions without
  replace authority, and copies only rights-safe small assets.
- [ ] Any source-conditioned generation is explicitly authorized; uses only a
  short muted/caption-cropped runtime reference; keeps source media out of the
  profile package and final edit; replaces identity/content through original
  bibles and prompt constraints; and records independent visual/rights review.
- [ ] Deliberate-scene-break model-native videos map one normally 4-5 second
  clean/annotated grid packet to one provider clip, show all grids and keyed
  notes plus the recurring-character card before generation, bind the approved
  character path/hash into every applicable provider call, invalidate approval
  after any identity-affecting fallback, reuse approved assets by default, and
  assign final transitions, captions/transcription timing, and audio placement
  to Remotion. The local generation envelope must prove approved identity/grid
  hashes and the effective character's presence in provider `reference_images`.
- [ ] Each annotated scene grid pins short IDs to the actual moving subjects or
  body parts and fixed displacement landmarks, draws motion arrows from those
  points toward mandatory endpoints, maps every visible ID to one literal note
  and provider-prompt instruction, and remains readable in the human review
  surface. Generic arrows drawn only between panels fail this check.
- [ ] Inspect generated clips for annotation leakage. Point IDs, arrows, panel
  labels, rulers, and prompt notes are control surfaces, not final pixels;
  repair, explicitly accept, or exclude any clip that renders them.
- [ ] The result does not impersonate a creator, claim an unselected named
  profile, trigger generation/spend without authority, or separate a profile's
  example from its package.
