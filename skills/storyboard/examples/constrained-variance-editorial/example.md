# Constrained-variance editorial example

For each measured narration beat:

1. write literal-evidence, causal-physical, and context/scale concepts;
2. select one relationship before searching for assets;
3. bind one viewer-state change to a 4-5 second target;
4. name two or three story-bearing reveals;
5. gather a quiet shared background, unique dominant topic family, and unique
   narration-specific foreground family;
6. verify tight alpha bounds, rendered visible mass, subject-level halftone,
   and clean background at final resolution;
7. run independent scene-cited story review.

Example beat:

```yaml
id: S03
state_change: full intent -> compressed carrier
concepts:
  - {id: S03-A, relationship_type: literal_evidence, visual_thesis: source and summary side by side}
  - {id: S03-B, relationship_type: causal_physical, visual_thesis: page narrows through a conveyor}
  - {id: S03-C, relationship_type: context_scale, visual_thesis: two desks divided by a mail chute}
selected_concept_id: S03-B
reveals: [source enters, conveyor narrows, summary exits]
main_topic_family_id: document-compression-machine
foreground_family_id: narrowing-conveyor
```

The verifier may prove timing, reveal count, family variance, geometry, and
treatment receipts. It must still return the six independent judgment
dimensions; it never emits a synthetic “Vox score.”
