# Visual Design

## Purpose

Define frontend look, taste, hierarchy, and visual-system direction once the functional UI shape is known.

## Public API / Entrypoints

- `SKILL.md`: main visual-design workflow
- `references/*`: register, numeric taste dials, design brief, and critique guidance

## Minimal Example

1. Confirm `prd` workflow mode has settled the workflow.
2. Classify product vs brand register.
3. Set scene sentence and a visual concept from the product's world.
4. Sketch three directions, pick one, then set numeric taste dials and the visual system.
5. Render the key screen at real viewport, critique, and refine.
6. Create or update a durable design brief for substantial UI work.
7. Record reference traits and anti-traits, then hand constraints to `impl-plan`.

## How to Test

- Confirm the skill routes broken workflows back to `prd` workflow mode.
- Confirm the output gives implementation-ready visual constraints.
- Run `python3 skills/skill-creator/scripts/quick_validate.py skills/visual-design`.
