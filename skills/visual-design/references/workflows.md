# Workflows

## Visual Direction

1. Confirm the functional basis.
2. Classify product vs brand register.
3. Write the scene sentence.
4. Find the visual concept and pass the concept test.
5. Sketch three directions; choose one and record the rejected ones.
6. Set taste dials.
7. Define typography, color, spacing, radius/elevation, media, and motion vocabulary.
8. Run the render, critique, and refine loop from `SKILL.md`.
9. Record reference traits as `adopt | adapt | reject` constraints.
10. Hand accepted visual context to `impl-plan`, with the rendered mock as reference evidence; `design.md` stays the baseline.

## Visual Polish

1. Diagnose hierarchy, rhythm, typography, color, responsiveness, and AI tells.
2. Preserve existing design-system constraints (see the existing-design-system
   branch in `SKILL.md`).
3. Recommend the smallest visual change that fixes the main issue, then
   render and re-score it.
4. Hand off concrete implementation constraints.
